Try the extension

Each page imitates a sign-in form. Press Send me a code, then don't touch anything: the code should appear in the field by itself.

  • Single field: one input with autocomplete="one-time-code".
  • Boxes: six one-character inputs (maxlength=1) with auto-advance, like Apple or Microsoft.
  • Boxes 3+3: six inputs in two groups, no maxlength, the page's script does the limiting.
  • Overlay: one invisible input on top of six drawn boxes, like the input-otp library.
